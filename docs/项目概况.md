# 7-eonmol 项目概况

> 本文是项目的详细概况（约 1,300 字正文 + 附表），可直接用于附件、申报材料与答辩稿。
> 所有数字均取自本仓库当前交付状态（默认权重 v10，2026-09-30），出处见文末「数字来源」。
> 口径约定：**第一优化轴是原始对接分（AutoDock Vina，越负越强）**；类药性、新颖性、ADMET 为门槛与约束，不是首要指标。

---

## 一、项目定位

7-eonmol 是一个面向 GPCR 靶点的分子生成模型与配套流水线。我们不针对某一个分子做优化，而是把"给定一个 GPCR 口袋结构，当天拿到一批可送验的候选分子"做成可复用的能力：

- **输入**：口袋结构（PDB 文件 + 口袋中心坐标）；
- **输出**：能长在口袋里、并附带对接分与类药性指标的小分子候选（SDF）；
- **形态**：生成 → 过滤入库 → 对接打分 → 排序输出，全流程自动；
- **门槛**：Windows 单机可跑，单批 50 个分子约 10 分钟（RTX 4070 Laptop 单卡），脚本与配置全部开源。

## 二、要解决的问题

GPCR 是上市药物最集中的靶点家族（800 多个成员），但常规做法有两个卡点：

1. **化学空间极大**：靠枚举或随机采样，很难高效命中可成药的区域；
2. **类药性与新颖性互相拉扯**：生成结果要么像已知配体，要么结构难以合成。

我们的做法是把这两件事**放进生成过程**，而不是等生成完再筛。

## 三、技术方案

模型基于开源框架 Pocket2Mol（等变图神经网络，逐原子自回归生成，能理解原子在三维空间的朝向；本项目权重 3.712 M 参数）。在此基础上做了三处改动，**均不改变网络结构、不新增可训练参数，对任意权重生效**：

### 3.1 模型本体：层数与各层作用

模型主体是等变图神经网络，逐原子自回归生长（每一步决定"放什么原子、放在哪、是否继续"）。当前权重 **总参数 3.712 M**，实测分解与各层职责如下：

| 模块 | 参数 | 占比 | 结构与职责 |
|---|---|---|---|
| 原子嵌入 ×2 | 0.003 M | 0.1% | 蛋白/配体原子类型与化学特征 → 复合图节点特征 |
| **编码器 `encoder`** | **2.984 M** | **80.6%** | **6 层**等变消息传递（256 标量通道 / 64 方向通道、edge 64、key 128、**4 头注意力**、截断半径 10 Å、kNN 48）；输出每个原子的标量 + 方向特征 —— **理解口袋与当前分子状态** |
| 元素/键头 `field` | 0.421 M | 11.4% | GVP + 边注意力分类（128 标量 / 32 向量、4 头、kNN 32）；预测**元素类别**（词表 C/N/O/F/P/S/Cl）、是否放原子、**键级** |
| 位置头 `pos_predictor` | 0.241 M | 6.5% | **MDN 三分量**（μ/σ/π）预测新原子的三维位置分布 —— **原子长在哪里** |
| **终止头 `frontier_pred`** | **0.0535 M** | **1.4%** | 预测原子是否仍是"可生长边界"；**无边界即终止生成** —— **决定分子大小（何时停止的总开关）** |

**关键机制**：实测生成过程**每步恰好增加 1 个重原子**（8 份采样日志、410 个分子逐条验证）⇒ **分子大小 = 停止步数**。因此控制尺寸的着力点就在"停止决策"：训练侧改终止监督、采样侧改判定阈值或尺寸窗（见 3.4）。

### 3.2 引导束搜索：奖励项 + 惩罚项（生成时引导）

束搜索的排序概率乘以"化学分数增益"，也就是把**奖励**与**惩罚**同时写进生成过程，而不是等生成完再筛：

| 项 | 表达 | 作用 |
|---|---|---|
| **奖励**（类药性、合成可及性） | `QED·w_qed + (1 − SA/10)·w_sa` | 把"像药、好合成"的分支在束搜索里加权；w_qed = w_sa = 1.0 |
| **惩罚**（多样性 / 防塌缩） | `− w_div · 最大 Tanimoto` | 惩罚"与已生成分子太像"的分支，防止全库塌缩到单一骨架；w_div = 0.5，单步最多扣 0.5 分 |
| **放大**（引导力度） | `exp(λ · [奖励 + 惩罚])`，乘到束排序概率上 | λ = 3.0 指数放大整个化学分数（含惩罚项）；**λ = 0 与原版逐位一致**，可随时关闭回退 |

- 效果：QED 中位 **0.667 → 0.803（+20%）**，第二个随机种子复现（0.688 → 0.821，+19%）；
- 代价可控：合成可及性不受损（100% 分子 SA ≤ 6），多步生长的产出代价平均约 7%。

### 3.3 多靶点微调框架与高密度数据集

- 数据集 `gpcr_mass_v1`：**12,244 对**「口袋—配体」（训练 10,407 / 验证 1,837；A2A 5,384、D3 4,734、5HT2B 1,332、β2-AR 794），由 Vina 对接构建；
- 数据治理四重过滤：元素词表、类药性门槛、同配体去冗余、按结构划分并做泄漏自检；
- 微调：以官方权重为起点，2,000 步正式微调（约 7 分钟一次），**对接成功率 98.6%**；
- 经同协议十臂对比确认不劣于官方权重后，**晋级为当前默认权重 v10**。

### 3.4 采样侧尺寸控制

- 机制规律：实测生成过程**每步恰好增加 1 个重原子**（8 份采样日志、410 个分子逐条验证）⇒ 分子大小等价于"何时停止"；
- 实现：在采样轨迹内设置重原子数上限/下限（下限强制继续生长、上限到位即判定完成）；
- 效果：分子量中位 **302.5 → 370–444 Da**，分子量 < 340 的小分子占比 **59% → 4–8%**；
- 工程形态：默认关闭时与原版逐位一致，参数写入运行配置，可独立开关、独立复核。

## 四、筛选与打分口径（四层）

| 层 | 内容 |
|---|---|
| ① 生成时引导分（奖励 − 惩罚） | 奖励 = QED + (1 − SA/10)；惩罚 = w_div × 最大相似度（w_div = 0.5）；两者合成后经 λ = 3.0 指数放大，乘到束排序概率上（λ = 0 与原版逐位一致） |
| ② 入库硬门槛 | PAINS/BRENK 子结构警报、MW 250–500、LogP 1–5、QED ≥ 0.40、SA ≤ 6、元素限定 C/N/O/F/P/S/Cl、环数 ≥ 1、去冗余 |
| ③ 候选字段 | 对接分 Vina（第一优化轴）、QED、SA、类药性综合分（QED + 1 − SA/10）、新颖性最大 Tanimoto、ADMET 分级（A/B/C，含 hERG/BBB/血浆蛋白结合/溶解度） |
| ④ 库级评估 | 富集与 ROC、Pareto 前沿、姿态置信度、选择性指数 |

## 六、可信度验证（不只报结果）

- **逆向阳性对照**：737 个已知 A2A 活性分子走同一条对接管线，728 个成功（**98.6%**）、均值 **−9.32** kcal/mol、强于 −10 的占 **22.1%** —— 说明管线本身可信；同时我们的库**强结合比例约为已知集的 2.5 倍**。
- **新颖性**：库内分子与上述 737 个已知分子的最大相似度中位 **0.306**、最高 **0.549**，**94.7%** 的分子低于 0.4，没有一个达到 0.85；Top50 候选最高相似度 **0.495**（全部低于 0.56）。
- **成药风险**：ADMET 规则化筛查（hERG、CYP、AMES、血脑屏障、血浆蛋白结合、溶解度）已对本代库重跑：A2A 库分级 **A 102 / B 237 / C 56**，候选清单中 A 级 **77** 个；D3 候选 A 21、5-HT2B 候选 A 27。
- **可复现**：全部脚本、运行配置、随机种子与日志归档；文档与页面中每个数字都可用仓库脚本重算。

## 七、与官方权重的关系（如实说明）

- 同协议十臂对比：**4 个更好、4 个打平、2 个更差**，平均领先 **0.15 kcal/mol**（95% 置信区间跨 0）⇒ 结论是"**打平略优**"，不宣称全面提升；
- **唯一显著优于官方权重的是引导束搜索**（A2A，p = 0.0004）；
- 靶点间表现不均衡：D3 口袋更深窄疏水，强结合比例偏低（5.7%）；β2-AR 本代对接明显更差（中位 −9.81 对旧库 −10.91），已按决策**关闭其生成入口、不计入交付**；
- 与上一代（v2）库相比：A2A **显著更好**（−9.70 → −10.13，p = 0.0002），D3 / 5-HT2B 无显著差异；两代采样口径不同（每批 200 → 50、步数 60 → 40），故新旧差异是"权重 + 口径"的综合效果，不能单归因于权重。

## 八、工程与可复现

- 一键入口：桌面 GUI（免安装 exe，双击启动）、命令行、批量挂机脚本三种形态；
- 单批 50 分子约 10 分钟，RTX 4070 Laptop 8 GB 单卡；环境内置，解压即用；
- 交付物：`results/`（三靶点库 + 候选清单 + 三维结构文件）、附件文档、演示材料；
- 历史归档：官方权重库（四靶点 8,904 → 入库 5,864）及全部下游分析保留在 `results/official_weight_library/`，可逐文件对照。

## 九、已知局限与下一步

**已知局限（如实留痕）**

- 本代库未重跑：选择性指数、六维综合 Tier、库级 ROC/Pareto、姿态置信度（候选表中对应列为空，历史库仍有完整记录）；
- D3 强结合比例偏低；样本规模受采样口径限制（每批 50 分子）；
- 与官方权重只做到"打平略优"，尚未在结合强度上取得整体显著优势。

**下一步**

1. **短期（赛前）**：Top50 候选人工复核 → 选 5–10 个送结合实验 → 实验结果回填；
2. **中期（3–6 个月）**：扩充更多 GPCR 口袋数据、重启微调；把管线复用到酶、离子通道等其他靶点家族；
3. **长期**：把实验反馈接入引导分数，形成"生成—验证—再训练"的主动学习循环。

> 7-eonmol 是我们自研的 GPCR 小分子生成模型：在开源模型 Pocket2Mol（能理解原子三维朝向的图神经网络）上用自建的 12,244 对口袋—配体数据做微调，默认权重为 v10。输入口袋结构，输出能长在口袋里、并带对接分与类药性指标的候选分子，从生成、过滤入库、对接打分到排序输出全部自动完成，Windows 单机单批 50 分子约 10 分钟，脚本开源。我们改了三处：生成时用引导束搜索把"类药、易合成"的方向放大（QED 中位 0.667 → 0.803，+20%，两种子复现）；用 12,244 对数据做 2,000 步微调（对接成功率 98.6%），确认不劣于官方权重后晋级为默认权重；加入尺寸控制，把分子量中位从 302.5 拉回 370–444 Da。三个靶点共采样 1,151 个、入库 707 个：主靶点 A2A 入库 395 个，对接均值 −10.00 kcal/mol，强于 −10 占 54.2%（同一管线下 737 个已知活性分子为 −9.32、22.1%）；库内 94.7% 的分子与已知活性集相似度低于 0.4。我们不宣称全面提升：与官方权重是打平略优（4 更好/4 打平/2 更差，均值 −0.15），唯一显著领先的是引导束搜索；D3 是已知弱项，β2-AR 已关闭生成入口。
