## §6 方法论纪律（血泪换来的硬规则，**违反即出错**）

1. **单种子不下结论**。`ab_docking_compare.py` 在只有 1 个种子时**只输出
   `PROVISIONAL(未证实)`**，不得据此晋级。
2. **噪声尺度**：同臂**重复运行**的 Vina 中位噪声 ≈ **0.14**；**种子间**噪声 ≈ **0.7**。
   判断效应显著必须用后者。我曾据此两次过早宣布改进、两次被第二种子推翻。
3. **必须同时报「原始 Vina」与「配体效率 LE」**，并在两臂尺寸差 >15 % 时警告。
   Vina 与分子大小强相关；只比原始分会把"分子更小"误读成"亲和力更差"。
4. **选点用生成指标，不用验证损失**。本项目多次证明两者背离
   （曾出现 val 1.97→0.77 而生成 QED 0.597→0.408）。
5. **出货目标是 `diversity_w = 0.5`**（`design.py`/`predict.py` 默认注入）。
   A/B 必须先确认评测目标与出货目标同源，否则结论无效。
6. **网格没扫完不下结论**（我曾只凭第一个点就宣布阈值 −0.25 是甜点，被 −0.5 推翻）。
7. **不得使用 `git add -A`** —— 本仓库**有并发写作者**在提交 `docs/deck_7eonmol/**`（演示 PPT），
   且它**正在读取 `docs/任务状态与记忆.md`**。只添加自己负责的路径。
8. **失败与自我更正必须留痕**，不得删除或改写历史结论；更正要在原处加显式撤回标注。
