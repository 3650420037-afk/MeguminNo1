# 微调实验 v3 —— 报告（诚实记录：未晋级）

- 目标：训练出**属于本项目自己的** Pocket2Mol 权重，并通过项目原生判据晋级
- 结论：**未晋级（NOT_PROMOTED）**。权重已交付为 `models/7-eonmol_ft_gpcr_v1.pt`，
  但**不作为默认**；默认仍是官方权重。本文记录全过程、真实数字与失败根因。
- 日期：2026-09-26 ｜ 靶点：A2A（4EIY）｜ 采样：60 样本 / 束宽 50 / 40 步 / 种子 2024

---

## 一、先修掉前两次失败的四个根因

| # | 前两次的根因 | 本次处置 | 结果 |
|---|---|---|---|
| 1 | 训练配体由「ETKDG 构象 + 只平移质心」生成，**31.5% 与蛋白粗穿模**（最近重原子距离中位 0.624 Å） | 改用**实验坐标**重建（`build_gpcr_v3.py::build_from_experimental`） | 新数据集 400 样本实测：最近距离中位 **2.874 Å**、**穿模 0%**（实验位姿参考 2.5–3.3 Å） |
| 2 | 保存并使用**最过拟合**的检查点（val 最低在 iter 1200，却用了 2000） | `train.py` 新增按验证损失存 `best.pt` + 早停 + `val_history.jsonl` | 两次训练分别早停于 iter 4400 / 2000，`best.pt` 明确留痕 |
| 3 | `batch_size=1` 时梯度噪声极大（实测标准差 > 均值，极差 35.8） | 新增 `grad_accum`，有效 batch = 8 | 训练损失仍噪声大但参数更新稳定 |
| 4 | 训练数据**化学组成不对**（RCSB 共晶配体里 CLR 胆固醇 253 个、去垢剂/辅酶等共 36%；CLR+TEP 两分子占 41%） | 建库阶段加**类药性过滤 + 同配体去冗余 + 元素词表过滤** | 807 对 → **262 对**（train 223 / val 39） |

另外修掉了两处**评测诚信**问题：

- **数据泄漏**：原划分按"配体对"随机，同一口袋会同时进入训练与验证。改为**按结构（PDB ID）划分**，
  并加自检；`build_report.txt` 记录 `structure_overlap=0`。
- **训练前验收门**：新增 `train.py --verify-dataset`，逐样本执行 transform，失败即拒绝开训
  （此前一次训练因数据里有词表外元素、在 iter 43 崩溃，白跑）。

## 三、真正拿到了什么（这是本次实验的实质收益）

本次微调在**两个可测轴上是改善的**，且是旧微调做不到的：

1. **口袋穿模率 5.97% → 0%**：旧微调会产生与蛋白原子重叠的分子（最差 0.064 Å），
   新微调在 60 个样本上零穿模。
2. **配体-口袋接触距离更接近实验参考**：新微调 2.35–2.54 Å，基线 3.22 Å
   （实验共晶位姿参考 2.5–3.3 Å）。即生成的分子**更贴合口袋**，而不是离壁更远。
3. **合成可及性显著改善**：SA 中位 2.72 vs 基线 3.83（越低越易合成）。

**代价**：QED 中位 0.682 vs 0.744；**完成分子数 23 vs 63**。

## 四、为什么仍然失败 —— 根因已定位到具体机制

采样日志给出了决定性证据：

```
基线:     [Pool] Queue 50 | Finished 63 | Failed 0
新微调:   [Pool] Queue 50 | Finished 7  | Failed 0
```

**`Failed = 0`** —— 分子不是重建失败（不是化学无效），而是**根本不会停止生长**，
一直留在队列里直到用尽步数。在 30 样本/20 步的试点规模下，三个不同检查点
（iter 800 / 2000 / 3200）**完成数全部为 0**，说明这不是某个检查点的问题。

**机制**：分子"何时停止生长"由 focal（前沿）头决定，而它高度依赖**口袋的大小与形状**。
本数据集的问题是**每个口袋只有 1.04 个训练样本**（223 对 / 225 个结构）：

| 数据集 | 口袋数 | 每口袋样本数 | 能否学到"停止"策略 |
|---|---|---|---|
| 旧微调集 `gpcr_multitarget_v2` | 4 | ≈96 | 能（所以产量保住了 67） |
| 新数据集 `gpcr_ft_v3` | 225 | **1.04** | **不能** |

旧数据只有 4 个受体、每个受体近百个配体类似物，模型能把"这个口袋多大多满就停"记下来；
新数据是 225 个不同 GPCR 结构各一条，模型看到的是"每次换一个口袋、只给一个例子"——
停止策略无从泛化。

**这也修正了此前技术全书 §4.4 的归因**：那里把失败归为"数据规模不足/无梯度信号/无法复训"，
更准确的表述是**"每口袋样本数不足导致停止策略不可学"**，而不是单纯的总量问题
（新数据集总量 262 比旧的 479 少，但真正致命的是每口袋 1 个）。

## 六、下一步（按性价比排序，均有本轮证据支撑）

1. **冻结终止头，只训化学头**（最省、最对症）。已定位到 `MaskFillModelNN.field` 内的
   focal/分类子模块；把它一并冻结，终止行为保持预训练解，同时让元素/键/位置头适配 GPCR。
   预期能同时保住产量与穿模 0%。
2. **提高每口袋样本密度**而不是总量：对少数几个目标受体（如 A2A/B2AR/D3/5HT2B）各收集
   50+ 个共晶或对接位姿，凑出"每口袋数十样本"，而不是 225 个口袋各 1 个。
   这与旧数据"有效但穿模"的差别只在于**位姿是否实验来源**。
3. **在 4 个目标受体上重建"实验坐标 + ChEMBL 类似物对齐"**：以共晶配体为模板做 MCS 对齐，
   把 ChEMBL 活性分子放到实验位姿上（既保留旧数据的每口袋密度，又修正穿模）。
4. **若目标只是提升 QED**：不动权重。引导束搜索（λ=3）已把 QED 中位从 0.667 提到 0.803（+20%），
   性价比高于微调。

## 七、可复现性

```bash
# 1) 抓取 GPCR 复合物(738 条目)
python src/scripts/fetch_gpcr_structures.py --workers 8 --outdir data/gpcr_pdb_raw
# 2) 用实验坐标建库 + 类药性治理 + 按结构划分
python src/scripts/build_gpcr_v3.py --src data/gpcr_pdb_raw --out data/gpcr_ft_v3 \
    --workers 6 --split-by structure --val-ratio 0.15 --drug-like medium --max-per-ligand 8
# 3) 训练前验收门(必须通过)
python train.py --config configs/train_gpcr_ft_head.yml --verify-dataset
# 4) 微调
python train.py --config configs/train_gpcr_ft_head.yml --logdir logs
# 5) 按生成质量选检查点(含口袋叠合度)
python src/scripts/select_ckpt_by_generation.py --ckpts <ckpt> --target A2A \
    --num-samples 60 --beam 50 --max-steps 40 --seed 2024 --keep-dir outputs/ab
# 6) 与基线严格 A/B
python src/scripts/select_ckpt_by_generation.py \
    --ckpts models/pretrained_Pocket2Mol.pt <ckpt> --target A2A \
    --num-samples 60 --beam 50 --max-steps 40 --seed 2024 --keep-dir outputs/ab
python src/scripts/judge_promotion.py outputs/ab/pretrained_Pocket2Mol outputs/ab/<ckpt> outputs/decision.txt
```

全部种子、环境与耗时记录在 `logs/<run>/checkpoints/best.json` 与 `logs/seeds.md`。
