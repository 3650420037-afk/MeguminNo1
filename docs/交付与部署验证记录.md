## 3. 终端版

### 3.1 小规模生成（`design.py`，纯生成）

```bash
python design.py --target A2A --num-samples 4 --beam 20 --max-steps 10 --seed 2024 --outdir outputs/deploy_check
# 返回码 0, 用时 29.3 秒, SDF=1, SMILES=1
# 产出: SDF/0.sdf (RDKit 3D, 10 重原子) 与 SMILES.txt -> c1ccc2cnccc2c1
```

> 该分子随后被入库规则拒收（`mw_out_of_range (129.2)`，库规则为 MW∈[250,500]），属**预期行为**而非故障；
> 10 步上限只能长出 10 个重原子，尺寸必然偏小。

### 3.2 全链路出清单（`predict.py`，评测主入口）

```bash
python predict.py --target A2A --num-samples 10 --beam 50 --max-steps 30 --seed 2024 \
    --outdir outputs/predict2 --results-dir outputs/predict2/results
# 返回码 0；入库分子 8 个 -> 清单候选 8 个（含结构文件 8 个）
# 耗时: 生成 187.6 s / 入库 1.5 s / 打分 0.5 s / 合计 191.3 s
```

### 3.3 复用已交付的库重出清单（不占 GPU，秒级）

```bash
python predict.py --library results --top 300 --target A2A
# 返回码 0, 合计约 3 秒, 395 个入库分子 -> 300 条候选 + 300 个结构文件
```

## 5. 本轮修掉的两个真实部署缺陷

| 缺陷 | 复现方式 | 影响 | 修复 |
|---|---|---|---|
| 候选清单「结构文件」列指向 `outputs/…`（被 `.gitignore` 排除） | 克隆后打开 `results/results.csv` | 300/300 结构文件在他人机器上 100% 失效，违反附件5 第四条「结构文件随附并在清单中标注」 | 用 README 记录的一键命令重出清单，路径改为 `results/structures/…`；D3/5HT2B 清单同步改指 `results/<靶点>/structures/`。指标列零改动（逐格比对确认） |
| `design.py --help` / 运行日志在重定向输出时崩溃 | `python design.py --help > log.txt`（中文 Windows 为 GBK、Linux C locale 为 ASCII） | 评测平台按 README 复核时极可能以重定向方式运行，`⚠`/`−` 触发 `UnicodeEncodeError`，进程直接退出 | `design.py`/`predict.py`/`train.py` 统一把 stdout/stderr 重设为 UTF-8 + `errors=replace`（guarded，不涉及模型逻辑） |
