# logs/ · 训练与验证日志

> 附件5 第二节要求提交「训练 / 验证日志、随机种子记录」。本目录即为此用途。

## 提交规则

`.gitignore` 对本目录采用**黑名单**（而不是整目录排除），因此：

| 内容 | 是否提交 | 说明 |
|---|---|---|
| `logs/<run>/log.txt` | ✅ | 每次训练/验证的完整文本日志（含每步 loss、验证指标、耗时） |
| `logs/<run>/*.yml` | ✅ | 该次运行实际使用的配置副本（`train.py` 会随日志一起归档） |
| `logs/**/checkpoints/*.pt` | ❌ | 检查点权重，体积大（实测约 850 MB）且可重现 |
| `logs/**/models/` | ❌ | 训练时自动归档的模型代码副本，与 `src/models/` 重复 |
| `logs/**/*.0` | ❌ | 运行期中间产物 |
| `logs/README.md`、`logs/seeds.md` | ✅ | 本文件与随机种子记录 |

## 目录约定

`train.py` 每次运行会新建 `logs/<配置名>_<时间戳>/`，内含：

```
logs/<config>_<YYYY>_<MM>_<DD>__<HH>_<MM>_<SS>/
├── log.txt          训练日志（本目录提交的主要内容）
├── checkpoints/     检查点（不提交）
├── models/          本次运行的模型代码归档（不提交）
└── <config>.yml     配置副本
```

采样日志则写在 `outputs/<批次>/` 下（见 README「九、数据与模型资产」）。

## 随机种子记录

各类运行使用的随机种子统一记录在 [`seeds.md`](./seeds.md)，便于逐项复现。

## 关于报告中的结果

本 README 与 `docs/` 引用的训练结果（含**未晋级的两次微调实验**）对应的日志均保留在
本目录中，可逐行核对；微调未晋级的原因分析见 `docs/7-eonmol_技术全书.md` 与
`ModelCard.md`。项目**不隐瞒失败结果**，也不把失败的实验从日志中删除。
