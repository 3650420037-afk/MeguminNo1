|---|---|---|---|---|
| A2A | **−12.31** | −11.88 | +0.43 | 旧 |

A2A 是唯一有旧库**全量**对接的目标，可做全量对全量：
旧 2,931 个 均值 **−9.68**、38.8% 强于 −10、最强 −13.51；
新 521 个 均值 **−9.69**、**42.2%** 强于 −10、最强 **−14.45**
→ **整体持平，新高强度比例略好**（但旧库 top-50 更强，说明旧的强结合尾部更厚）。

**结论（不粉饰）**：**四靶点并非全面提升。**
- **规模**：新库只有旧库的 18%–30%——这是真实的退步，因为批次从 73 降到 12/6；
- **QED**：四个靶点**全部低于**旧库；
- **SA**：A2A 与 5HT2B 改善，B2AR 与 D3 变差；
- **MW**：四个靶点全部变大；
- **对接**：仅 **B2AR 提升**，A2A 明显不如，D3/5HT2B 基本持平。

**为什么受控 A/B 说"更好"、库级却说"不如"？——两件事的评测口径都不同**

> ⚠ 2026-09-27 修正：下面第一条括号里的"晋级"已不成立。当初的 A/B 是在
> `diversity_w = 0`（无多样性惩罚）下做的，而出货药库用的是 0.5；
> 在出货目标下复验，QED 两个种子都更低，**晋级不成立**（详见 `../ModelCard.md`）。

- ~~模型晋级用的是**受控 A/B**~~ → 受控 A/B 用的是**与出货不同的目标函数**
  （同靶点、同样本数/束宽/步数/种子，但 `diversity_w` 为 0）：
  在**那个口径下**新模型 QED 与基线相当、SA 更好、口袋叠合度更好。
  这是唯一把"模型差异"与"采样预算差异"分开的实验，但它**没有对齐引导目标** —— 这是缺陷。
- 而本表的库级对比**混杂了采样预算差异**：旧库是 73 个批次 + 束宽 100 / 50 步的配置，
  新库只有 12/6 个批次 + 束宽 50 / 60 步。旁证：同一个官方模型在束宽 50 / 40 步下
  QED 中位是 0.744，而旧库（束宽 100 + 73 批次）达到 0.825 —— **采样预算本身就带来 0.08 的差距**。
- 因此"库级不如"**主要来自我没把生成预算对齐**，而不是模型变差。
  若要库级追平或超过，正确做法是**用与旧库相同的束宽与更多批次重跑**（纯算力问题）。

**复现命令**

```bash
# 1) 生成（12 批次，种子 2024–2042）
python design.py --target A2A --num-samples 200 --beam 50 --max-steps 60 --seed <SEED> \
    --outdir outputs/library_v2
# 2) 入库 + 打分 + 出清单
python predict.py --skip-design --target A2A --top 300 \
    --runs outputs/library_v2/<session>/sample_for_pdb_* \
    --outdir outputs/predict_v2 --results-dir outputs/results_v2
# 3) 对接（AutoDock Vina）
python src/scripts/docking_pipeline.py --receptor data/targets/4EIY_A2A受体.pdb \
    --center=-0.42,8.53,17.13 --smiles-file <SMILES> --out <OUT> --exhaustiveness 4
# 4) 带对接分重出清单
python predict.py --library <库目录> --target A2A --top 300 --rank-by vina
```
