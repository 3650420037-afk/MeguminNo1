# 安装说明
# --------------------------------------------------------------------------
# 1) torch 与三个 PyG 扩展必须与 CUDA 版本匹配。本环境为 CUDA 12.4:
#      pip install torch==2.6.0 --index-url https://download.pytorch.org/whl/cu124
#      pip install torch-scatter==2.1.2 torch-cluster==1.6.3 torch-sparse==0.6.18 \
#          -f https://data.pyg.org/whl/torch-2.6.0+cu124.html
#    其他 CUDA 版本请到 https://pytorch.org 与 https://data.pyg.org/whl/ 选对应轮子。
#
# 2) 纯 CPU 也能运行(推理明显更慢): 命令行加 --device cpu。
#
# 3) 本工程含 Windows / PyTorch 2.6 兼容补丁(src/utils/misc.py、src/utils/transforms.py、
#    src/models/common.py), 请勿降级 torch 到 2.6 以下, 也不要删除这些补丁。
#
# 4) 分子对接(可选)需要第三方可执行文件, 不通过 pip 安装:
#      tools/vina/vina.exe                      AutoDock Vina
#      tools/openbabel/Library/bin/obabel.exe   Open Babel
#    缺失时 predict.py 仍可完成生成与筛选, 只是清单中不含对接分数。
#
# 5) 仓库根的 env_cuda113.yml 是**原版 Pocket2Mol 的 Linux 环境文件**
#    (python 3.8 / pytorch 1.10.1+cu113 / rdkit 2022.03), 与本项目实测环境不一致,
#    仅供溯源参考, 请勿用它复现环境。
