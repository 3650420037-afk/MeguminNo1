## 默认模型 `7-eonmol_ft_gpcr_v3.pt`

来源：架构实验 **v8** 的 iter 800（`logs/train_gpcr_arch_v8_2026_09_27__11_30_12/checkpoints/800.pt`，
训练配置 `configs/train_gpcr_arch_v8.yml`）。相对上一版 v2 的两处结构性改动：

| 改动 | 前 | 后 |
| --- | --- | --- |
| 解冻编码器（分层学习率） | 冻结，只训 0.728 M（19.6 %） | 全网络可训 3.883 M；encoder 1e-5 / 头部 1e-4 / frontier_pred 5e-4 |
| `frontier_pred` 容量 | 128/32/1 层，0.0535 M（1.4 %） | **256/64/2 层，0.2258 M（5.8 %）** |

- 数据：`data/gpcr_dock_v1`（307 对 / 4 个口袋 / 每口袋 40–127 样本 / 零穿模）
- ⚠ **架构随权重走**：`frontier` 容量记录在权重文件自己的 `config` 里，
  而 `src/sample_for_pdb.py` 正是按 `ckpt['config'].model` 构建模型，故可直接加载。

### 晋级证据（`diversity_w = 0.5`，即**出货目标**；A2A；同种子成对；双种子）

**生成指标**（判据 vs 同种子官方基线）：

| 候选 | 种子 | 完成 | QED 中位 | SA 中位 | 骨架 | 穿模率 | 四项判据 |
|---|---|---|---|---|---|---|---|
| 官方基线 | 2024 | 63 | 0.7857 | 3.9147 | 47 | 0.0 % | — |
| 官方基线 | 2025 | 61 | 0.7258 | 3.2274 | 39 | 0.0 % | — |
| **v3（本权重）** | 2024 | 64 | **0.8504** | **3.6605** | 47 | **0.0 %** | **全过** |
| **v3（本权重）** | 2025 | 60 | **0.8073** | **3.0278** | **55** | **0.0 %** | **全过** |

**对接级（第一优化轴 = 结合强度）**：

| 种子 | 权重 | 生成数 | Vina 均值 | **Vina 中位** | 最强 | ≤−10 |
|---|---|---|---|---|---|---|
| 2024 | 官方基线 | 53 | −9.373 | **−9.49** | −11.57 | 35.8 % |
| 2024 | **v3** | 52 | −9.279 | **−9.455** | −11.28 | **36.5 %** |
| 2025 | 官方基线 | 61 | −10.247 | **−10.31** | −12.46 | 55.7 % |
| 2025 | **v3** | 60 | −9.866 | **−10.335** | −12.41 | **60.0 %** |

**如实表述**
- **结合强度与官方基线打平**（中位差 −0.04 / −0.03 kcal/mol）。
  必须给出噪声底：**同一条臂的运行间差异实测约 0.14 kcal/mol**，
  故 0.03–0.04 的差**只能称"打平"，不得称"更强"**。
- **其余各轴不劣、多数更好**：QED 两个种子都更高（+0.065 / +0.082）、
  SA 两个种子都更低（更好）、骨架数打平或更多（47/47、55/39）、
  穿模率两个种子均为 0 %、完成数相当（64/63、60/61 → 停止策略健康）。
- ⚠ **局限（2026-09-27 更新，重要）**：上表**只覆盖 A2A**。把验证扩展到其余靶点后发现
  **B2AR 上 v3 的结合强度明显更差**（Vina 中位 −8.47 vs 基线 −9.27，**+0.80**，
  约为同臂噪声底 0.14 的 6 倍，单种子）：
  | 靶点 | 种子 | 基线中位 | v3 中位 | 差 | 判定 |
  |---|---|---|---|---|---|
  | A2A | 2024 | −9.49 | −9.455 | −0.04 | 打平 |
  | A2A | 2025 | −10.31 | −10.335 | −0.03 | 打平 |
  | **B2AR** | 2024 | −9.27 | **−8.47** | **+0.80** | **更差** |
  | D3 / 5HT2B | 2024 | 待测 | | | |
  **因此准确表述是**：v3 相对**官方权重**是「**亲和力互有胜负**（A2A 打平、B2AR 更差）
  + 类药性与骨架多样性更优」；只有相对**被替换的 v2** 才是全面更优
  （v2 在 A2A 双种子的亲和力与 QED 都更差）。
  若多靶点亲和力普遍劣于官方权重，`DEFAULT_CKPT` 应回退官方权重，
  v3 的定位改为"类药性/多样性更优的备选"。**在多靶点结果齐备前，
  不得宣称 v3"在所有轴向上不劣于官方权重"。**

### 被替换的 `7-eonmol_ft_gpcr_v2.pt`

同一口径（`diversity_w = 0.5`、A2A、双种子）下 v2 **两个种子的结合强度都明显更差**
（Vina 中位 +1.03 / +0.81，≤−10 富集 26.8→8.0 % 与 59.0→30.2 %），
且 QED 两个种子都更低 → 判 **NOT_PROMOTED**，不再作为默认。
其权重保留，以便按 `--ckpt models/7-eonmol_ft_gpcr_v2.pt` 复现该结论。


使用方式：

```bash
python design.py --target A2A                       # 默认即 v3
python design.py --target A2A --ckpt models/pretrained_Pocket2Mol.pt   # 跑官方基线对照
python design.py --target A2A --ckpt models/7-eonmol_ft_gpcr_v2.pt     # 复现 v2 被替换的结论
python design.py --target A2A --ckpt models/7-eonmol_ft_gpcr_v1.pt     # 对照早期未晋级的 v1
```

## 早期权重 `7-eonmol_ft_gpcr_v1.pt`（未晋级，保留对照）

在实验坐标数据集（每口袋仅 1 条）上训练，穿模 0%、SA 2.72、接触距离 2.35 Å 三项更好，
但完成分子数 23 vs 基线 63 不达标，判 NOT_PROMOTED。保留以便复现该结论。

## 权重内容

`torch.load` 后为字典，字段如下（实测）：

| 键 | 类型 | 说明 |
|---|---|---|
| `config` | EasyDict | 模型与训练配置 |
| `model` | OrderedDict | 模型参数（state_dict） |
| `optimizer` | dict | 优化器状态 |
| `scheduler` | dict | 学习率调度状态 |
| `iteration` | int | 训练迭代数 |

该文件**只包含 `state_dict`**，不含项目模块的 pickle 引用，因此可以安全地
把 `src/models/` 代码目录整体移动而不影响加载。

> PyTorch 2.6 起 `torch.load` 默认 `weights_only=True`。本仓库在
> `src/utils/misc.py` 中注册了所需的安全全局对象（补丁），加载前请先
> `import utils.misc`（`design.py` / `predict.py` / notebook 均已处理）。

## 本项目是否微调过权重

**没有作为最终交付。** 两轮微调实验均未通过 A/B 对照，已整体回退；
最终交付使用上述官方权重，模型的贡献在**采样层（引导束搜索）**而非权重。
详见仓库根 [`ModelCard.md`](../ModelCard.md) 第 1 节与第 7 节。

## 训练/微调产出的权重放哪里

`python train.py` 会把检查点写到 `logs/<config>_<时间戳>/checkpoints/`，
不会写入本目录，以免与最终交付权重混淆。
